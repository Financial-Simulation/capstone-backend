## 이 리포트가 확인하지 않는 것

- 원자료에서 값을 다시 추정하는 과정은 이번 묶음에 넣지 않았다. 값은 기준 구현 kernel.py v1.6에서 가져왔고, 원자료 품질 관문·추정·보정 결과는 설계 보고서 7.1(품질 관문)·7.3(보정·백테스트)이 근거다.
- 실업급여 상·하한과 지원금 상한은 2026년 명목값으로 고정되어 있다 (보고서 8.1 한계).
